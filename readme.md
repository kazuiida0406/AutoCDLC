# AutoCDLC

Automatic Rocksmith CDLC Builder

Converts Guitar Pro (`.gp7`) files and audio (`.mp3`) into Rocksmith Custom Downloadable Content (CDLC).

## Features
- Convert GP7 tabs and track metadata into CDLC package structure
- Embed MP3 audio and map timing metadata
- Simple command-line usage for batch processing

## Requirements
- Python 3.8+ (or specify runtime)
- Guitar Pro `.gp7` files
- MP3 audio files aligned with the tab

## Installation
Clone the repository and install dependencies (if any):

```powershell
git clone https://example.com/your-repo.git
cd AutoCDLC
# Install dependencies if requirements.txt exists
pip install -r requirements.txt
```

## Usage
Basic usage example:

```powershell
# Replace with actual CLI entrypoint
python main.py --gp7 song.gp7 --audio song.mp3 --out output_folder
```

Check the repository for more detailed options and examples.
